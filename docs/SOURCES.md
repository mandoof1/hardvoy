# Sources and licences

hardvoy ships its own lab, its own corpus and its own fixtures. Nothing is
downloaded at build time and nothing is committed that came from somebody
else's repository or dataset.

## Artifacts committed here

| file | origin |
|---|---|
| `tests/fixtures/report-tor-and-direct.json` | produced by this tool on 2026-11-13 by `hardvoy scan --egress direct --egress tor --circuits 3` on the Arch/CachyOS host named in the README. Contains relay nicknames and IP-free circuit evidence. |
| `tests/fixtures/report-direct-leaky.json` | produced by `hardvoy scan --egress direct --profile leaky` on the same host. |
| `tests/fixtures/ice-leaky.txt` | synthetic ICE candidates written for this repository (RFC-style `candidate:` lines with documentation addresses). |
| `tests/fixtures/ice-mdns.txt` | synthetic mDNS-only candidates, same reason. |
| `docs/tables/tor-demo-run.txt` | verbatim stdout of the definition-of-done run. |
| `docs/tables/stability-direct.txt` | verbatim stdout of `hardvoy stability --egress direct --profiles stock,rfp,leaky --runs 5`. |
| `assets/*.{gif,png,cast,tape}` | recordings of real runs on this host, regenerated by `make assets`. |

No private engagement data is included: every address in the fixtures is either
a RFC791-style private address (`192.168.8.88`, `10.0.0.7`), a documentation
prefix, or an address of the machine this was built on.

## Specifications read while implementing (no code copied)

* TLSRecord / TLS handshake and extension registry — RFC 8446 and RFC 8448
  (GREASE).
* JA3 — Salesforce's published JA3 specification (fields
  `version,ciphers,extensions,elliptic_curves,ec_point_formats`).
* JA4 — FoxIO's published JA4 specification (the wire shape implemented here).
* HASSH — Salesforce's HASSH specification for SSH KEXINIT fingerprints.
* W3C WebDriver specification (session, navigate, execute script, screenshot).
* Tor control-port specification (`SIGNAL NEWNYM`, `GETINFO circuit-status`,
  `SETCONF` for onion services, cookie authentication).
* ICE candidate syntax — RFC 5245 / RFC 8445 `candidate:` line format.

The implementations in `src/tlsf.rs`, `src/sshf.rs`, `src/wd.rs` and
`src/tor.rs` are written against those documents; none of the reference code is
linked, vendored or ported.

## Host tools used at runtime (not redistributed)

| tool | version at test time | used for |
|---|---|---|
| `tor` | 0.4.9.16 | tor egress: own instance, own data dir, control port |
| `firefox` | 160.0 | the browser under audit |
| `geckodriver` | 0.37.1 | WebDriver session for Firefox |
| `node` | system | version inventory only |
| `tshark` | 4.7.4 | version inventory only (handy for cross-checking a capture by hand) |

`hardvoy tools` prints the versions it saw. A scan needs only `firefox` and
`geckodriver`; a Tor egress additionally needs `tor`.
